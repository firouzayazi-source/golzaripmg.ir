# golzaripmg.ir — کدِ سفارشیِ سایت

افزونه‌های سفارشیِ وردپرسِ سایتِ آرایشِ دائمِ گلزاری. با هر پوش روی `main` منتشر می‌شوند و سایت خودش آن‌ها را برمی‌دارد. قواعدِ کار در `CLAUDE.md` است.

## ساختار

| مسیر | کار |
|---|---|
| `wp-content/plugins/golzari-updater/` | به‌روزرسان، نشانیِ سلامت و نشانی‌های فقط‌خواندنیِ مدیر |
| `scripts/check.sh` | وارسیِ پیش از پوش |
| `scripts/verify-bump.php` | قرمز اگر افزونه عوض شده و نسخه نه |
| `scripts/build.php` | ساختِ zipها و `manifest.json` در `dist/` |
| `tests/visual/` | آزمونِ دیداری با وردپرسِ کوچک و SQLite |
| `tools/snap.mjs` | عکس از سایتِ زنده، با حافظه‌ی محلی |
| `.github/workflows/release.yml` | وارسی ← آزمونِ دیداری ← انتشار ← صبر برای گزارشِ سایت |

## راه‌اندازی (یک بار)

### ۱) دیده شدنِ انتشارها از سایت
سایت فایل‌ها را از انتشارِ گیت‌هاب برمی‌دارد، پس مخزن **عمومی** است (در این کد هیچ رمزی نیست).

### ۲) نصبِ اولِ به‌روزرسان (دستی)
1. بعد از اولین انتشارِ سبز، از بخشِ انتشارهای مخزن فایلِ زیر را بگیرید:
   ```
   golzari-updater-1.0.0.zip
   ```
2. پیشخوانِ وردپرس ← افزونه‌ها ← افزودن ← بارگذاری ← فعال‌سازی.
3. ابزارها ← «به‌روزرسانِ گلزاری» ← دکمه‌ی «وارسی و نصبِ همین الان».

از این به بعد هر ۱۵ دقیقه خودکار است.

### ۳) کاربر و رمزِ برنامه
کاربرِ `claude` با نقشِ مدیرِ کل و یک رمزِ برنامه. رمز فقط در متغیرهای محیطِ کار گذاشته می‌شود، نه در چت و نه در مخزن.

### ۴) محیطِ کار
محیطِ جدای «Golzaripmg» با:
```
GOLZARI_WP_USER=claude
GOLZARI_WP_APP_PASSWORD=<رمزِ برنامه>
```
و `golzaripmg.ir` در «دامنه‌های مجاز».

## خواندنِ سایتِ زنده
سایت از خارج مستقیم جواب می‌دهد و پل لازم نیست. ابزارِ عکس و کارِ `live` مستقیم می‌خوانند، با سقفِ ۲ درخواستِ هم‌زمان. اگر روزی هاست آی‌پیِ خارج را بست، پلِ جدای همین سایت ساخته و نشانی‌اش در `GOLZARI_RELAY_URL` گذاشته می‌شود.
